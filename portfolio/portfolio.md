## 最重要的方向

- 这是横版 A4 作品集，不是普通全屏滚动官网。
- 页面尺寸必须固定为 `297mm × 210mm`。
- CSS 必须包含 `@page { size: A4 landscape; margin: 0; }`。
- 每个页面使用 `.page` 容器，一页就是一张横版 A4。
- 屏幕预览可以居中显示 A4 页面，打印时必须无边距、无阴影、无额外空白页。
- 不要改成浏览器全宽滚动页；不要删除 A4 尺寸规则。

## 风格参考

参考 Apple 产品页的设计气质，而不是复制 Apple 素材：

- 简洁、克制、留白大。
- 标题短、有力，正文少而清楚。
- 每页文字必须少：项目页只保留标题、一句话介绍和关键词，不要写三段说明。
- 不做花哨动效，不做炫酷背景，不做渐变大海报。
- 截图是主要视觉，不是装饰图。
- 图片不要放在页面正中间排成画廊。
- 项目图片区应该靠右、贴底或形成产品展示舞台，像设备/产品截图展示。
- 不要出现布局重叠、文字遮挡、图片挤压。

## 不要展示的内容

- 不要像简历一样展示完整工作经历。
- 不要展示教育背景。
- 不要展示技能与能力清单。
- 不要堆大量 bullet。
- 不要写长段落；每个项目不要超过一段正文。

## 技术要求

- 优先使用单文件 HTML + CSS。
- 不依赖外部 CDN 字体、图标或远程图片。
- 使用相对路径引用本地图片。
- 保持屏幕预览和打印版一致。
- 不要使用会导致打印或预览变样的大量动画。
- 不要为了排版使用大面积绝对定位，避免错位和重叠。
