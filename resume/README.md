## 严禁改动

以下规则是为了避免打印预览中文消失、尺寸不是 A4、导出 PDF 裁切等问题。

不要随意改：

- `@page { size: A4; margin: 0; }`
- `.sheet` 或 `.page` 根容器的 `width: 210mm; height: 297mm;`
- `@media print`
- `font-family`
- `print-color-adjust`
- 页面根容器 `.sheet` 或 `.page`

必须保留中文打印字体栈：

```css
font-family: "Hiragino Sans GB", "Heiti SC", "PingFang SC", "STHeiti", "Songti SC", "Microsoft YaHei", Arial, sans-serif;
```

不要改回：

```css
-apple-system, BlinkMacSystemFont, "PingFang SC", ...
```

之前这样会导致 Chrome 打印预览中文丢失，只剩英文、数字和符号。

## A4 与打印要求

- 页面尺寸必须是 `210mm × 297mm`。
- 浏览器预览可以有灰色背景和阴影。
- 打印时必须无阴影、无外边距、无灰背景。
- 打印预览必须只有 1 页。
- 打印预览必须显示中文。
- 不允许内容溢出 A4。
- Chrome 打印预览里如果中文消失，优先检查 `font-family` 是否被改坏，不要继续改布局。
- 打印预览里如果不是 A4，优先检查根容器是否仍是 `210mm × 297mm`，不要用 px 替代 mm。

验证方式：

1. 浏览器打开 `resume-a4.html`
2. `Cmd + Shift + R` 强刷
3. `Cmd + P`
4. 目标打印机选择“另存为 PDF”
5. 检查：
   - 中文是否正常显示
   - 是否只有 1 页
   - 是否没有裁切
   - 是否没有空白第二页

## 利众项目业务理解（给 Mimo 的简历写作参考）

利众项目的根目录 README 是工程文档，覆盖了接口、数据库、迁移脚本和权限规则，但对简历来说不够直观。写简历时不要照搬技术细节，要先讲清业务。

### 一句话介绍

```text
利众客户速录与融资咨询管理系统，是面向车辆融资咨询企业的内部业务协同系统，用来把线下获客、客户登记、客服跟进、产品准入判断和转化结果追踪线上化。
```

### 项目不是做什么

```text
它不是放贷系统，不做征信查询，不做自动审批，也不直接给客户放款。
它的核心是企业内部的客户服务、资料整理、产品准入筛选和跟进协同。
```

### 业务背景

```text
车辆融资咨询业务原本依赖线下获客和人工跟进：合作商带来客户，客户资料分散在微信、表格和图片里，客服需要反复询问车辆、额度、征信、收入、房产等信息，再凭经验判断哪些银行产品可能符合准入。这个过程容易出现客户归属不清、重复跟进、资料缺失、产品判断慢、转化结果难追踪等问题。
```

### 业务角色

```text
平台管理员：管理企业、套餐、协议、短信、通知、智能匹配配置和调用统计。
企业主：管理本企业员工、产品库、客户线索、业绩、缴费续费。
客服：认领客户、补录资料、推进客户状态、创建匹配工单、执行产品匹配。
合作商：通过专属二维码获客，查看自己带来的客户和业绩。
客户：扫码进入 H5，手机号登录后提交车辆融资咨询资料并查看进度。
```

### 核心业务闭环

```text
1. 平台创建企业并开通服务。
2. 企业创建管理员、客服和合作商。
3. 合作商生成专属二维码，用于线下物料推广和客户扫码。
4. 客户扫码进入 H5，提交基础资料，可继续补充进阶资料。
5. 客户进入企业待办池，客服认领后跟进。
6. 客服补录资料、记录电话联系、推进待评估 / 评估中 / 评估价已出 / 跟进中 / 成交 / 未成交等状态。
7. 企业维护产品库，录入银行公开产品资料、准入条件、资料要求和征信规则。
8. 客服根据客户情况创建匹配工单，系统按严格准入规则筛选可办理产品。
9. 智能匹配支持客服输入整段客户描述，系统用规则 + LLM 提取字段，人工确认后生成匹配工单草稿。
10. 系统通过企业微信和站内通知提醒新客户、认领、状态变更、支付成功等关键事件。
11. 平台和企业可查看合作商、客服、管理员、企业维度的业绩统计和调用/操作日志。
```
