## 一句话任务

请制作一个横版 A4 尺寸的一页式个人官网 / 作品集页面，用简洁、克制、清晰、接近 Apple 产品页的视觉方式展示张欣杰是谁、适合什么岗位、做过哪些 0-1 产品项目、具备哪些 AI 产品和业务系统落地能力。页面要能直接打印，屏幕预览效果就是最终打印效果。

## 使用场景

这个页面不是普通网页首页，也不是长滚动作品集网站，而是一张可以作为“作品集封面 + 一页简历 + 项目概览”的横版 A4 页面。

主要使用场景：

- 投递产品经理 / AI 产品 / FDE 方向岗位。
- 面试前发给 HR 或面试官，帮助对方快速理解候选人经历。
- 打印或导出 PDF 后作为面试材料。
- 作为在线作品集入口页，引导访问作品集链接。

面试官在 20 秒内应该能看懂：

- 候选人做过车辆融资咨询场景下的 0-1 业务系统。
- 候选人能把线下业务流程拆成线上模块。
- 候选人做过客户登记、跟进、产品匹配、转化追踪等完整闭环。
- 候选人有 AI 辅助录入、自然语言解析、内容安全数据标注等 AI 相关经验。
- 候选人不是纯技术岗，也不是单纯 UI 设计岗，而是偏业务落地、产品推进、AI 原生工作流的产品型人才。

## 页面定位

页面标题可以理解为：

```text
张欣杰｜产品经理 / AI 产品 / FDE 方向作品集
```

页面气质：

- 简洁
- Apple-like
- 大留白
- 真实产品截图驱动
- 信息有层级但不喧闹
- 成熟
- 商务
- 克制
- 清晰
- 有作品集感
- 信息密度适中但不拥挤
- 适合打印，不依赖屏幕特效

不要做成：

- 校园简历模板

- 纯技术简历

- 动效很多的网页
- 只有文字、没有项目截图的简历页

## Apple-like 简洁风格要求

这里说的“模仿 Apple”不是使用 Apple 的商标、素材或具体页面资产，而是参考它的设计气质：

- 大面积白底或极浅灰底。
- 干净的内容分区。
- 真实产品截图作为主要视觉，而不是装饰插画。
- 标题短而有力，正文克制。
- 较少颜色，主要依靠字号、字重、留白和图片大小建立层级。
- 圆角、阴影、线条都要非常轻。
- 不堆满卡片，不做复杂背景。
- 不用花哨渐变、玻璃拟态、发光边框。
- 让项目截图像产品发布页里的设备 / 界面展示一样被认真排版。

推荐视觉关键词：

```text
clean editorial, Apple-like portfolio, product screenshots, quiet premium, white space, print-first
```

不推荐视觉关键词：

```text
cyberpunk, neon, dashboard overload, blue gradient hero, poster style, heavy animation
```

## 横版 A4 打印要求

页面必须是横版 A4，而不是普通网页宽屏比例。

CSS 必须包含类似配置：

```css
@page {
  size: A4 landscape;
  margin: 0;
}

html,
body {
  margin: 0;
  padding: 0;
}

.page {
  width: 297mm;
  height: 210mm;
}
```

打印时要求：

- 只有 1 页。
- 不产生空白第二页。
- 不裁切内容。
- 不出现滚动页效果。
- 不出现浏览器默认页边距。
- 不依赖背景图才能看清信息。
- 打印预览中文必须正常显示。
- 打印时背景和颜色保持清楚。
- 屏幕预览看到的布局、图片位置、字号和层级，打印时必须基本一致。
- 不要为打印单独隐藏大块内容，也不要让屏幕版和打印版变成两套设计。

建议添加：

```css
* {
  box-sizing: border-box;
}

body {
  -webkit-print-color-adjust: exact;
  print-color-adjust: exact;
}

@media print {
  body {
    background: #ffffff;
  }

  .page {
    box-shadow: none;
    margin: 0;
  }
}
```

## 屏幕预览与打印一致性

核心要求：

```text
屏幕预览是什么样，打印 / 导出 PDF 就是什么样。
```

实现建议：

- 用固定 A4 横版页面容器，不做响应式长网页。
- 屏幕模式可以在页面外加浅灰背景和轻微阴影，模拟纸张。
- 打印模式只去掉页面外阴影和灰色浏览器背景，不要改变内部布局。
- 图片、文字、项目模块在屏幕和打印中保持同样的位置和比例。
- 不要在 `@media print` 中重排内容。
- 不要打印时隐藏图片。
- 不要屏幕展示多列、打印改成单列。
- 不要使用必须依靠 hover、滚动、轮播或动画才能看到的信息。

允许差异：

- 打印时去掉页面外阴影。
- 打印时去掉 body 的灰色背景。
- 打印时关闭 transition / animation。
- 打印时微调抗锯齿或颜色保真。

不允许差异：

- 屏幕看到 3 个项目，打印只剩 2 个项目。
- 屏幕有项目图片，打印图片消失。
- 屏幕是横版 A4，打印变成多页长文档。
- 屏幕排版很好看，打印变成拥挤文字块。

动效要求：

- 不要做复杂动效。
- 不要做滚动触发动画。
- 不要做轮播、翻页、视差。
- 最多允许非常轻微的页面加载淡入，但打印中必须完全不依赖它。
- 推荐直接不写动画，让页面像一张精致排版的作品集纸面。

## 字体要求

必须使用中文打印友好的字体栈，避免 Chrome 打印预览时中文消失。

必须使用：

```css
font-family: "Hiragino Sans GB", "Heiti SC", "PingFang SC", "STHeiti", "Songti SC", "Microsoft YaHei", Arial, sans-serif;
```

不要改成：

```css
-apple-system, BlinkMacSystemFont, "PingFang SC", ...
```

原因：

之前中文打印预览出现过丢字问题，只剩英文、数字和符号。优先保持上面的中文字体栈。

## 颜色要求

整体以白底或极浅灰底为主，用深色文字和少量强调色。风格要更接近 Apple 式的简洁产品页，而不是传统蓝色商务简历。

推荐颜色：

```css
--ink: #111827;
--text: #172033;
--muted: #334155;
--soft: #475569;
--line: #d7dde5;
--accent: #1d1d1f;
--accent-blue: #174a6a;
--paper: #ffffff;
--tint: #f5f5f7;
--panel: #fbfbfd;
```

正文颜色不能太浅：

- 正文建议 `#111827` 或 `#172033`。
- 说明文字不浅于 `#243244`。
- 时间、岗位、链接等辅助信息不浅于 `#334155`。
- 避免 `#888`、`#999`、`#6b7280`、`#94a3b8` 这类打印后偏淡的颜色。

不要使用：

- 大面积蓝色背景。
- 大面积渐变。
- 荧光色。
- 黑底霓虹风。
- 彩色标签堆满页面。
- 装饰性背景图。
- 为了“科技感”增加的发光、毛玻璃、强阴影。

### 推荐版式 B：左侧身份栏 + 右侧图片叙事

左侧约 26%：

- 姓名、定位、联系方式。
- 工作经历。

右侧约 74%：

优点：

- 个人信息稳定。
- 图片展示空间最大。
- 适合 Apple-like 的图文叙事。

### 推荐版式 C：三段式产品案例页

横向分成三段：

- 第一段：身份和核心定位。
- 第二段：利众客户速录主项目，最大面积，多图。
- 第三段：代驾项目多图 + 抖音项目文字。

优点：

- 最接近产品发布页的节奏。
- 视觉更简洁。
- 适合展示截图。

推荐选择：

优先采用版式 A 或 B。重点是图片要有主次，不要把 8-10 张图平均铺满导致拥挤。

### 图片排版建议

图片要像作品集里的产品截图，而不是附件缩略图。

推荐做法：

- 主项目使用一张大图 + 2-4 张小图。
- 小图可以使用横向胶片式排布，但不要做可滚动轮播。
- 代驾项目可以用 2 × 2 小图网格。
- 手机端截图可以放在窄框里，后台截图可以放在宽框里。
- 图片圆角控制在 `6px - 10px`。
- 阴影非常轻，或只用细边框。
- 图片下方可加 1 行短 caption，但不要每张图都长篇解释。

不要做：

- 不要轮播。
- 不要 hover 后才出现核心信息。
- 不要动效切图。
- 不要把图片裁得看不出界面。
- 不要用深色遮罩盖住截图。
- 不要用大面积样机壳抢空间。
- 不要把 10 张图等宽平铺成一堆小碎片。

### 图片和文字的关系

每个有图项目应该遵循：

```text
项目标题 -> 一句话业务问题 -> 我的关键动作 -> 真实截图组 -> 项目结果
```

图片用来证明项目真实存在和复杂度，文字用来说明候选人做了什么。

不要让图片和文字割裂：

- 图片旁边要有简短说明。
- 每个项目至少有一句“这个项目解决什么问题”。
- 每个项目至少有一条“我负责什么”。
- 主项目必须有“结果 / 价值”。
